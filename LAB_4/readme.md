## การหาพื้นที่เหมาะสมในการเพาะปลูกข้าวในจังหวัดสุพรรณบุรี
## Spatial Suitability Model
#### 1. การ Normalize แต่ละ Factor
- ปรับค่าของแต่ละปัจจัยให้อยู่ในช่วง 0–1 ด้วยวิธี Min-Max Normalization เพื่อให้สามารถนำมารวมกันได้อย่างเหมาะสม เนื่องจากข้อมูลแต่ละตัวมีหน่วยและช่วงค่าที่แตกต่างกัน
- สำหรับปัจจัยที่มีความสัมพันธ์เชิงบวกกับความเหมาะสม เช่น Rainfall ใช้วิธีการปรับค่าโดยตรง (unitScale) เพื่อให้ค่ามากมีความเหมาะสมสูง ส่วนปัจจัยที่มีความสัมพันธ์เชิงลบ เช่น Elevation, Slope และ Distance to river ได้ทำการกลับค่า (invert) โดยใช้การคูณด้วย -1 และบวก 1 เพื่อให้ค่าที่ต่ำมีความเหมาะสมสูง ซึ่งสอดคล้องกับหลักการปลูกข้าวที่ต้องการพื้นที่ลุ่ม ราบ และใกล้แหล่งน้ำ
- Land Cover ได้ใช้การ reclassify โดยกำหนดคะแนนให้กับแต่ละประเภท เช่น cropland ได้ค่าสูงสุด (1) เนื่องจากมีความเหมาะสมอยู่แล้ว ขณะที่พื้นที่ประเภทอื่นได้รับค่าต่ำลงตามลำดับ เพื่อสะท้อนความแตกต่างของศักยภาพในการเพาะปลูก
#### 2. การกำหนด Weight และ Combine
- การรวมปัจจัยใช้วิธี Weighted Linear Combination (WLC) โดยกำหนดน้ำหนักให้แต่ละปัจจัยตามความสำคัญ และรวมค่าโดยใช้สมการ ดังนี้

**Suitability = (0.20×Rainfall)+(0.25×Elevation)+(0.25×Distance)+(0.20×Slope)+(0.10×Landcover)**
#### 3. การแบ่งระดับความเหมาะสม (Thresholds)
ผลลัพธ์ suitability ถูกแบ่งออกเป็น 3 ระดับ ได้แก่
- 1 = ความเหมาะสมน้อย
- 2 = ความเหมาะสมปานกลาง
- 3 = ความเหมาะสมสูง

ใช้ค่า threshold ที่ 0.5 และ 0.7 ซึ่งเป็นการแบ่งช่วงค่าจากผลลัพธ์ที่ผ่านการ normalize แล้ว (0-1) เพื่อให้สามารถแยกกลุ่มพื้นที่ได้อย่างชัดเจนและตีความง่าย

## Sensitivity Analysis
#### 1. เปลี่ยนน้ำหนักของปัจจัยที่สำคัญที่สุด ±20%
จากการปรับน้ำหนักของ Elevation และ Distance to water เพิ่มและลดลง 20% พบว่าค่า Mean Absolute Difference (MAD) มีค่าค่อนข้างต่ำ อยู่ประมาณ 0.012-0.013 แสดงว่าค่าความเหมาะสมของพื้นที่โดยรวมเปลี่ยนแปลงไม่มากเมื่อมีการปรับน้ำหนักของปัจจัยเหล่านี้ และการเปลี่ยนแปลงของ classification พบว่า 
- การ +20% ทำให้พื้นที่ที่เปลี่ยน class มีเพียงประมาณ 0.73-0.75%
- การ -20% ทำให้พื้นที่ที่เปลี่ยน class เพิ่มขึ้นเป็นประมาณ 7.96-8.03%

แสดงว่าการลดความสำคัญของปัจจัยบางตัวอาจทำให้การจัดระดับความเหมาะสมของพื้นที่เปลี่ยนแปลงมากกว่าการเพิ่มน้ำหนัก
#### 2. พื้นที่ไหนที่โมเดลให้ผลคงที่ (Robust) และพื้นที่ไหนที่ไม่แน่นอน?

#### 3. ผลต่อความเชื่อมั่นของโมเดล
ผลการวิเคราะห์แสดงให้เห็นว่าโมเดลมีความเสถียรค่อนข้างดี เนื่องจากการเปลี่ยนน้ำหนักของปัจจัย ±20% ทำให้ค่าความเหมาะสมเปลี่ยนแปลงเพียงเล็กน้อย และมีพื้นที่ที่เปลี่ยน class ในสัดส่วนที่ไม่มาก สรุปว่าโมเดลมีความน่าเชื่อถือในระดับหนึ่งสำหรับการประเมินความเหมาะสมของพื้นที่ปลูกข้าว
## Validation
- จากการตรวจสอบความถูกต้องด้วยข้อมูล validation จำนวน 237 จุด พบว่าโมเดลมีค่า Overall Accuracy (OA) = 60.76% และค่า Kappa = 0.37 ซึ่งโมเดลมีความสอดคล้องกับข้อมูลจริงในระดับปานกลาง ยังมีความคลาดเคลื่อนอยู่พอสมควร
- ผลการจำแนกในแต่ละ class พบว่า High suitability มีประสิทธิภาพดีที่สุด โดยมีค่า Precision สูงมาก (1.00) และ F1-score = 0.75 แสดงว่าเมื่อโมเดลทำนายว่าเป็นพื้นที่เหมาะสมสูงมักจะถูกต้อง ส่วน Low suitability มีประสิทธิภาพในระดับปานกลาง (F1-score ≈ 0.65) ขณะที่ Moderate suitability มีประสิทธิภาพต่ำที่สุด (F1-score ≈ 0.29) เนื่องจากโมเดลมีแนวโน้มทำนาย class นี้มากเกินไป ทำให้เกิด False Positive จำนวนมาก
- ค่า Macro-averaged F1 score = 0.56 แสดงว่าโดยรวมโมเดลมีประสิทธิภาพอยู่ในระดับปานกลาง และยังมีความไม่สมดุลของประสิทธิภาพระหว่างแต่ละ class
##### ข้อจำกัด
- แยกระดับ Moderate suitability ได้ไม่ดีเท่าไหร่ โมเดลนี้ใช้เป็นแนวทางเบื้องต้นในการประเมินความเหมาะสมของพื้นที่ปลูกข้าวได้ แต่ควรพิจารณาร่วมกับข้อมูลปัจจัยอื่นเพิ่ม เพื่อเพิ่มความแม่นยำของการวิเคราะห์
# คำถาม
### 1. ถ้ามีข้อมูล Ground Truth จริง คิดว่า Accuracy ของโมเดลนี้จะอยู่ในระดับใด? เพราะอะไร?

### 2. ปัจจัยที่ไม่ได้ใส่ในโมเดลแต่น่าจะสำคัญมีอะไรบ้าง? ทำไมถึงไม่ใส่?
- ชนิดดิน : ข้อมูลดินมีความละเอียดต่ำและต้องแปลผลหลายขั้นตอน ทำให้มีความยุ่งยาก  
- ระบบชลประทาน : จริง ๆ มีผลโดยตรงต่อการเข้าถึงน้ำมากกว่าระยะห่างจากแหล่งน้ำ แต่ข้อมูลโครงข่ายชลประทานที่ครบถ้วนและเป็น spatial data หาได้ยาก และประมวลผลค่อนข้างซับซ้อน
### 3. โมเดลนี้ใช้ได้ดีในระดับ Scale ใด (ตำบล / อำเภอ / จังหวัด) เพราะอะไร?
- โมเดลมีความแม่นยำระดับปานกลาง เหมาะกับการใช้ใน**ระดับจังหวัด** โดยนำมาใช้ดูภาพรวมของพื้นที่ เพราะ ยังมีบางคลาสที่โมเดลแยกได้ไม่ค่อยดี จึงไม่ควรนำไปใช้กับระดับเล็ก ๆ ที่ต้องใช้ความละเอียดเชิงพื้นที่ค่อนข้างเยอะ ข้อมูลอาจมีความผิดพลาดและอาจทำให้ตัดสินใจผิดพลาดได้ 
### 4. ถ้าต้องนำโมเดลนี้ไปอัปเดตปีละครั้ง ขั้นตอนใดที่ต้องทำซ้ำและขั้นตอนใดที่คงที่?
#### ขั้นตอนที่ต้องทำซ้ำทุกปี
- Rainfall : ปริมาณฝนเปลี่ยนตลอด
- Land Cover : การใช้ที่ดินมีการเปลี่ยนแปลงอยู่ตลอด เช่น พื้นที่เกษตรอาจกลายเป็นเมือง หรือเปลี่ยนชนิดพืชที่ปลูก
#### ขั้นตอนที่คงที่
- Elevation, Slope : ภูมิประเทศไม่เปลี่ยนในระยะสั้น
- Code, วิธี Normalize : โครงสร้างโมเดลยังเหมือนเดิม ใช้ซ้ำได้เลย
- Weights ของปัจจัย : ใช้ค่าเดิมได้ ถ้าแนวคิดโมเดลยังเหมือนเดิม
