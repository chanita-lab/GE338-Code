## 1. ออกแบบ Training Strategy
พื้นที่ศึกษาที่เลือก คือ บึงบอระเพ็ด จังหวัดนครสววรค์
### 1.1 แบ่งประเภทที่ดินเป็น 5 Class ได้แก่ 
- Water (น้ำ)
- Wetland Vegetation (พื้นที่ชุ่มน้ำ)
- Agriculture (เกษตรกรรม)
- Forest (ป่า)
- Urban (พื้นที่เมือง)
### 1.2 วิธีการสร้าง Training Samples
ใช้ข้อมูลจาก Dynamic World เป็นแหล่งอ้างอิง (Reference Dataset) : มีความสะดวกรวดเร็ว ครอบคลุมพื้นที่ใหญ่ มีหลาย class ใช้ train model ได้ง่าย เหมาะใช้เป็น reference เบื้องต้น แต่ไม่ใช่ ground truth จริง 100% ความแม่นยำจึงขึ้นอยู่กับลักษณะพื้นที่
### 1.3 การแบ่ง Train / Validation
- แบ่งข้อมูลSamples เป็นชุดTraining และชุดValidation โดยใช้วิธีสุ่ม (Random split) ในอัตรา 80/20 วิธีนี้ทำให้ข้อมูลถูกกระจายแบบสุ่ม โดยไม่มีอคติในการเลือกข้อมูลฝึกและทดสอบ
- แบบสุ่ม : เป็นการสุ่มจุดตัวอย่างทั้งหมด แล้วแบ่งเป็น train/test
  #### ข้อดี :
  ทำได้ง่ายและรวดเร็ว และเหมาะสำหรับข้อมูลที่ไม่มีโครงสร้างเชิงพื้นที่ชัดเจน
  #### ข้อจำกัด :
  เกิดปัญหา Spatial autocorrelation (ค่าพิกเซลใกล้กันมีลักษณะคล้ายกัน) อาจทำให้ค่า Accuracy สูงเกินจริง
- Spatial Cross-validation : แบ่งพื้นที่ออกเป็นโซน แล้วใช้บางโซนฝึก และอีกโซนทดสอบ
  #### ข้อดี :
  ลดปัญหา Spatial autocorrelation ทำให้มีความแม่นยำกว่า
  #### ข้อจำกัด :
  ทำยากกว่า ต้องออกแบบการแบ่งพื้นที่ และค่า Accuracy มักจะต่ำกว่า
### 1.4 Feature ที่ใช้
#### Spectral Bands : B2, B3, B4, B8
- B2 (Blue) : เหมาะสำหรับตรวจจับน้ำและตะกอน
- B3 (Green) : ช่วยแยกพืชพรรณและน้ำตื้น
- B4 (Red) : พืชดูดกลืนสูง ใช้แยกพืชออกจากดิน/สิ่งปลูกสร้าง
- B8 (NIR) : พืชสะท้อนสูงมาก เป็นแบนด์สำคัญในการจำแนกพืชพรรณ
#### Indices : NDVI, NDWI, NDBI
- NDVI : ใช้แสดงความหนาแน่นของพืช
- NDWI : ใช้ตรวจจับน้ำ 
- NDBI : ใช้ตรวจจับพื้นที่เมือง 
## 2. เปรียบเทียบ Algorithm
โมเดลที่ใช้ : Random Forest และ Gradient Tree Boost
#### - Random Forest
- Accuracy = 0.699 
- Kappa = 0.441
#### - Gradient Tree Boost    
- Accuracy = 0.690
- Kappa = 0.423

**สรุป** จากการเปรียบเทียบพบว่า Random Forest (RF) มีประสิทธิภาพโดยรวมสูงกว่า Gradient Tree Boost (GTB) โดยมีค่า Overall Accuracy และ Kappa สูงกว่าเล็กน้อย และให้ค่า F1-score ที่ดีกว่าในหลาย class โดยเฉพาะพื้นที่พืชและเกษตร แต่ก็ยังมีบาง class ที่ GTB ทำได้ดีกว่า อีกทั้ง RF มีความเสถียรและทนต่อ noise ได้ดีกว่า
## 3. วิเคราะห์ Feature Importance
Feature ที่ใช้ : Blue, Green, Red, NIR, NDVI, NDWI, NDBI
### 3.1 Feature ที่สำคัญ : NDBI Blue Green  
ทั้ง 3 Feature สอดคล้องกับความเป็นจริงทางกายภาพ โดย
- NDBI : ใช้แยกพื้นที่สิ่งปลูกสร้าง (Urban) พื้นที่เมืองจะสะท้อน SWIR มากกว่า NIR ถ้าค่าสูง = เมือง 
- Blue : มีความไวต่อความขุ่นของน้ำ, พื้นที่ชุ่มน้ำ (wetlands) ก็คือพื้นที่บริเวณบึงบอระเพ็ด
- Green : ตอบสนองต่อพืช และ chlorophyll
### 3.2 ตัด Feature ที่มีความสำคัญต่ำออก : NDVI
Overall Accuracyเดิม = 0.6991 เมื่อตัด NDVI ออก Accuracy = 0.6956 ซึ่งความแม่นยำลดลงเพียงเล็กน้อย แสดงว่าให้เห็นว่า NDVI ไม่ได้มีผลต่อโมเดลมากนัก เพราะยังมี NIR, Green, Red ที่สามารถใช้จำแนกพืชได้
## 4. ประเมินความไม่แน่นอน
### 4.1 Class ที่ถูกสับสนกันมากที่สุด 
**Agriculture ↔ Forest** เพราะ Agriculture กับ Forest มีลักษณะ spectral ใกล้กัน ทั้งสองเป็น vegetation โดยมีการสะท้อน NIR สูง, Red ต่ำ และ NDVI สูง เมื่อพื้นที่มีลักษณะพืชกำลังเติบโต นาข้าวมี canopy หนา และพื้นที่เกษตรมีต้นไม้ผสม ทำให้โมเดลแยกยาก
### 4.2 บริเวณที่โมเดลไม่แน่ใจ (Class Probability ต่ำหรือใกล้เคียงกัน)
มักพบในพื้นที่รอยต่อของการใช้ที่ดิน เช่น ขอบป่าที่ติดกับพื้นที่เกษตร หรือพื้นที่เกษตรที่อยู่ใกล้แหล่งน้ำ โดยเฉพาะพื้นที่เกษตรชุ่มน้ำ เช่น นาข้าว หรือพื้นที่เกษตรที่อยู่ใกล้บึง พื้นที่ลักษณะนี้มักมีทั้งน้ำและพืชปกคลุมอยู่ จึงมีลักษณะคล้ายกับพื้นที่ชุ่มน้ำ (wetland) ทำให้ค่าการสะท้อนแสงของพิกเซลมีความใกล้เคียงกัน ส่งผลให้โมเดลจำแนกคลาสได้ไม่ชัดเจนและเกิดความสับสนระหว่างคลาส
### 4.3 อธิบายความน่าเชื่อถือแผนที่ให้ Stakeholder
แผนที่การจำแนกการใช้ที่ดินที่สร้างขึ้นจากแบบจำลอง มีความแม่นยำโดยรวมประมาณ 70% จากการประเมินด้วย Confusion Matrix ซึ่งหมายความว่าโดยเฉลี่ยแล้วแบบจำลองสามารถจำแนกประเภทพื้นที่ได้ถูกต้องประมาณ 7 ใน 10 Pixel ผลการประเมินยังแสดงให้เห็นว่าแบบจำลองสามารถจำแนกพื้นที่บางประเภทได้ค่อนข้างดี เช่น พื้นที่ป่าไม้ แต่ในบางประเภท เช่น พื้นที่เกษตรและพื้นที่ชุ่มน้ำ อาจมีความสับสนกันบ้าง เนื่องจากมีลักษณะทางกายภาพและการสะท้อนแสงที่ใกล้เคียงกัน ดังนั้นแผนที่นี้สามารถใช้เพื่อดูภาพรวมของการกระจายตัวของการใช้ที่ดินในพื้นที่ศึกษาได้ค่อนข้างน่าเชื่อถือ

# คำถาม
### 1. ถ้าเพิ่ม Training Samples อีก 2 เท่า ความแม่นยำจะเพิ่มขึ้นเท่าไหร่?
#### Random Forest (50trees) vs Random Forest (100trees)
- เพิ่มจำนวน trees จาก 50 เป็น 100 ไม่ได้ช่วยเพิ่มความแม่นยำโดยรวมอย่างมีนัยสำคัญ โดยค่า Overall Accuracy แทบไม่ต่างกัน ซึ่งอยู่ที่ ≈ 0.70 
### 2. Spatial Autocorrelation ในข้อมูล Training มีผลต่อความแม่นยำที่รายงานอย่างไร?
- ทำให้ข้อมูลที่อยู่ใกล้กันมีลักษณะคล้ายกัน ส่งผลให้เมื่อแบ่งข้อมูลแบบสุ่ม Train/Test มีความสัมพันธ์กัน ทำให้โมเดลทำนายได้ง่ายและค่าความแม่นยำสูงเกินจริง เนื่องจากโมเดลไม่ได้เรียนรู้รูปแบบทั่วไปของข้อมูล แต่เรียนรู้ลักษณะเฉพาะของพื้นที่นั้นๆ ซึ่งมันไม่สะท้อน performance จริงในโลกจริง
### 3. Class ใดที่โมเดลทำได้แย่ที่สุด — แก้ได้ด้วยวิธีใดบ้าง?
- จากผล Confusion Matrix พบว่าคลาสที่โมเดลจำแนกได้แย่ที่สุดคือ Urban และ Wetland

**Urban** : สับสนกับพื้นที่เกษตรหรือพื้นที่โล่ง เพราะในภาพดาวเทียมบางบริเวณมีลักษณะการสะท้อนแสงคล้ายกัน

**Wetland** : สับสนกับพื้นที่เกษตร โดยเฉพาะพื้นที่เกษตรชุ่มน้ำ เช่น นาข้าวหรือพื้นที่ใกล้บึง ซึ่งมีทั้งน้ำและพืชอยู่ร่วมกัน
**วิธีแก้**
- เพิ่ม training samples ของคลาสที่จำแนกยาก เพื่อให้โมเดลเรียนรู้ลักษณะของคลาสได้ดีขึ้น
- เพิ่ม spectral indices เช่น NDWI ช่วยแยกน้ำได้ชัดขึ้น
- ใช้ multi-temporal data เพราะบางคลาส เช่น พื้นที่เกษตรหรือพื้นที่ชุ่มน้ำ จะมีการเปลี่ยนแปลงตามฤดูกาล ซึ่งช่วยให้โมเดลแยกประเภทได้ดีขึ้น
### 4. ถ้าต้องทำซ้ำ Lab นี้สำหรับพื้นที่อื่น อะไรคือสิ่งที่ต้องเปลี่ยน และอะไรที่ใช้ซ้ำได้?
#### สิ่งที่ต้องเปลี่ยน
- **การกำหนด training samples** เพราะสภาพการใช้ที่ดินในแต่ละพื้นที่ไม่เหมือนกัน จึงต้องปรับให้เหมาะสมกับพื้นที่นั้นๆ
- **ช่วงเวลา** เมื่อเปลี่ยนพื้นที่ก็ต้องดูลักษณะทางกายภาพของพื้นที่นั้นๆ เช่น ฤดูกาลของพืช หรือ ดูลักษณะสภาพภูมิอากาศว่าช่วงเวลาที่มีเมฆน้อย
#### สิ่งที่ใช้ซ้ำได้
- Model 
- features

สามารถใช้ซ้ำได้แต่ก็ต้องปรับรายละเอียดให้เหมาะสมกับพื้นที่
